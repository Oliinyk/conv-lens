# Встановлення Conv Lens

Ця інструкція для власника сайту, не для програміста. Технічних знань не потрібно.
Усе зводиться до одного рядка, який треба вставити на сайт.

---

## Що взагалі відбувається

Conv Lens — це окрема маленька програма, яка живе на **своїй адресі** (наприклад
`https://lens.ваш-домен.com`). Ваш сайт залишається таким, як був: ви лише додаєте
на нього один рядок, який каже браузеру відвідувача «надсилай події туди».

Один Conv Lens обслуговує скільки завгодно сайтів. Для кожного він видає свій ключ,
і дані сайтів ніколи не змішуються.

---

## Крок 1. Підняти Conv Lens

Потрібно зробити один раз. Виберіть те, що вам ближче.

### Варіант А. На своєму компʼютері (щоб спробувати)

Потрібен [Node.js](https://nodejs.org) версії 22 або новішої.

```bash
git clone https://github.com/Oliinyk/conv-lens.git
cd conv-lens
node bin/conv-lens.js serve
```

У терміналі зʼявиться адреса на кшталт `http://127.0.0.1:8777` — відкрийте її в браузері.

Важливо: ця адреса працює тільки на вашому компʼютері. Для справжнього сайту потрібен
варіант Б — інакше дані з сайту просто не дійдуть.

### Варіант Б. На Vercel (безкоштовно, за 10 хвилин)

1. Зробіть форк цього репозиторію до себе на GitHub.
2. На [vercel.com](https://vercel.com) натисніть **Add New → Project** і виберіть цей форк.
3. Відкрийте вкладку **Storage** проєкту → **Create Database** → **Turso** (або будь-яка
   база libSQL). Vercel сам пропише змінні підключення.
4. Натисніть **Deploy**.

Без бази Conv Lens теж запуститься, але писатиме в тимчасове сховище, і дані
зникатимуть. Дашборд попередить про це червоною смужкою.

### Варіант В. На своєму сервері

Так само, як варіант А, але вкажіть, що слухати треба зовні, і поставте перед
програмою nginx з HTTPS:

```bash
node bin/conv-lens.js serve --host 0.0.0.0 --port 8777
```

## Крок 2. Додати сайт

Відкрийте Conv Lens у браузері. Під час першого запуску він сам запитає три речі:

| Поле | Що вписати |
|---|---|
| **Адреса сайту** | Повна адреса разом з `https://` |
| **Назва** | Будь-яка, щоб ви впізнали сайт у списку |
| **Що це за сайт** | Виберіть свою платформу зі списку |

Вибір платформи — найважливіший. Conv Lens одразу складе правильний ланцюжок кроків
(каталог → картка товару → кошик → оформлення → покупка) і почне ловити натискання
кнопок «Додати в кошик» та «Оформити» **без жодних правок у коді сайту**.

Після цього ви побачите два значення. Збережіть обидва:

* **Код для сайту** — той самий один рядок.
* **Ключ доступу до дашборда** — без нього дашборд більше не відкриється. Покажемо один раз.

---

## Крок 3. Вставити рядок на сайт

Рядок виглядає так:

```html
<script src="https://lens.ваш-домен.com/cl/t.js?s=ВАШ_КЛЮЧ_САЙТУ" defer></script>
```

Його треба вставити **перед `</head>` на всіх сторінках**. Як саме — залежить від сайту.

### WordPress

Найпростіше — плагін із цього репозиторію, папка `integrations/wordpress/conv-lens`.

1. Запакуйте цю папку в zip.
2. WordPress → Плагіни → Додати новий → Завантажити плагін → виберіть zip → Активувати.
3. Налаштування → Conv Lens. Впишіть адресу Conv Lens і ключ сайту (це те, що
   стоїть у рядку після `?s=`). Збережіть.

Плагін додатково ловить події WooCommerce — додавання в кошик, помилки оформлення,
успішне замовлення разом із сумою, — тож у звіті буде видно реальні гроші.

### Google Tag Manager

Підходить будь-якому сайту, де вже стоїть GTM.

1. GTM → Теги → Створити → **Custom HTML**.
2. Вставте рядок цілком.
3. Тригер — **All Pages**.
4. Зберегти → **Submit**.

### Shopify

Адмінка → Online Store → Themes → **Edit code** → `layout/theme.liquid`.
Знайдіть `</head>` і вставте рядок перед ним.

### Сайт на конструкторі (Wix, Tilda, Webflow, Horoshop)

Шукайте в налаштуваннях пункт на кшталт «Код у head», «Власний код»,
«Скрипти аналітики» — і вставляйте туди.

## Крок 4. Перевірити, що працює

1. Відкрийте свій сайт у звичайному браузері, поклікайте.
2. Поверніться в Conv Lens → **Налаштування**.
3. Угорі блоку «Код для сайту» має бути зелений напис **«Код працює: дані приходять»**.

Якщо напис жовтий і каже, що нічого не прийшло, натисніть **«Перевірити встановлення»** —
Conv Lens сам відкриє ваш сайт і скаже, що саме не так:

* **коду на сторінці немає** — рядок не зберігся або потрапив не на той сайт;
* **у коді лишився приклад** замість вашої адреси і ключа;
* **стоїть ключ іншого сайту** — дані пишуться в чужий проєкт. Найчастіша помилка,
  коли сайтів кілька, і помітити її інакше майже неможливо.

Якщо перевірка каже, що код на місці, а даних усе одно немає:

* перевірте, що адреса Conv Lens відкривається з інтернету, а не лише у вас;
* якщо ваш сайт на `https://`, Conv Lens теж має бути на `https://` — браузери
  блокують звернення з захищеної сторінки на незахищену;
* блокувальники реклами Conv Lens не блокують, бо це ваш власний домен, а не
  зовнішній сервіс.

## Крок 5. Підлаштувати під себе (необовʼязково)

Все в **Налаштуваннях**, нічого редагувати в файлах не треба.

* **Кроки фунела** — додайте або перейменуйте кроки. «Адреса містить» — це шматок
  посилання, наприклад `/checkout`. «Сталася подія» — назва події, наприклад `purchase`.
* **Середній чек** — потрібен, щоб Conv Lens рахував втрати в грошах.
* **Зберігати дані** — типово 30 днів, старше видаляється саме.
* **Записувати** — на великому трафіку можна писати лише частину відвідувачів.
* **Опитування** — питати тих, хто збирається піти, чому вони не купили.

## Що робити, коли покупка не зараховується

Conv Lens вважає покупкою перехід на сторінку подяки (`/thank-you`, `/success` тощо) —
це налаштовано в пресеті вашої платформи. Якщо такої сторінки немає або вона
називається інакше, додайте в кроки фунела крок «Покупка» з потрібною адресою.

Щоб у звіті була ще й сума замовлення, попросіть того, хто робив сайт, додати один
рядок на сторінку подяки:

```html
<script>cl('goal', 'purchase', { value: 1234, currency: 'UAH' });</script>
```

де `1234` — сума замовлення.

## Якщо сайтів кілька

Один Conv Lens обслуговує скільки завгодно сайтів, і в кожного свої дані. Доступи бувають двох видів:

**Ключ власника** — той, що показав майстер при першому запуску. Відкриває всі сайти,
налаштування, додавання нових сайтів. Нікому стороннньому його не давайте.

**Посилання для клієнта** — своє в кожного сайту. Налаштування → **«Доступ для клієнта»** →
скопіювати. Людина за цим посиланням бачить звіти лише свого сайту і не може нічого змінити:
ні налаштувань, ні інших сайтів, ні видалення записів. Підставити в адресу чужий сайт теж
не вийде — ключ жорстко привʼязаний.

Якщо посилання кудись витекло — там же кнопка **«Відкликати доступ»**: стара адреса
перестає працювати, видається нова.

## Приватність

* IP-адреса зберігається, щоб відрізняти людей; разом з нею пишеться хеш із сіллю,
  яка змінюється щодня. Згадайте аналітику в політиці конфіденційності сайту.
* Паролі не записуються ніколи: поля типу `password` пропускаються.
* Хто просив себе не відслідковувати (Do Not Track), типово не записується.
* Дані лежать у вашій базі, не в чужому сервісі, і зникають після терміну зберігання.
