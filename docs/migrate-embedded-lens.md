# Переїзд із вбудованої лінзи на окремий інстанс

Що робити, коли Conv Lens був вшитий у сайт (як це було в `homeboys-cutaway`), а тепер
має працювати як окремий продукт. Кроки для людини з доступом до Vercel; усі зміни в коді
вже зроблені.

Порядок важливий: спершу підняти нову лінзу, потім переключити сайт, і лише потім
прибирати стару. Інакше між деплоями загубляться дані.

---

## 1. Підняти окремий інстанс Conv Lens

1. Форк `github.com/Oliinyk/conv-lens` → на [vercel.com](https://vercel.com) **Add New → Project**.
2. **Storage → Create Database → Turso.** Vercel сам пропише змінні підключення.
3. У **Settings → Environment Variables** додати:
   - `CONV_LENS_SALT` — будь-який довгий рядок, сіль для хешування IP;
   - `CONV_LENS_TOKEN` — якщо хочете задати ключ дашборда самі, а не отримати його від майстра.
4. **Deploy.** Запишіть адресу, яку видасть Vercel, — далі це `CONV-LENS-HOST`.

Краще одразу повісити власний піддомен (наприклад `lens.ваш-домен.com`): адреса потрапить
у код сайту, і міняти її потім — це ще один деплой лендінгу.

## 2. Додати сайт

Відкрийте нову лінзу в браузері. Майстер запитає адресу сайту, назву і тип.
Для лендінгу з формою або кнопками звʼязку беріть **«Сайт послуг / лендінг (заявки)»**.

Збережіть обидва значення, які він покаже: **ключ доступу до дашборда** (показується один раз)
і **ключ сайту** — те, що стоїть у коді після `?s=`.

## 3. Для сайтів із canvas або 3D — увімкнути «справжню сторінку»

**Налаштування → Як відтворювати сесії → «відкривати справжню сторінку».**

Типовий режим — зі знімка верстки; він працює завжди, але canvas на знімку виглядає
порожнім прямокутником, бо DOM не містить намальованого. У режимі «справжня сторінка»
плеєр відкриває сайт у фреймі і керує ним через міст у тегу Conv Lens.

Сторінка має публікувати `window.__replay` — у `homeboys-cutaway` це є внизу `main.js`.

## 4. Переключити сайт на нову лінзу

У `<head>` сайту має лишитись один рядок:

```html
<script src="https://CONV-LENS-HOST/cl/t.js?s=КЛЮЧ_САЙТУ" defer></script>
```

Для `homeboys-cutaway` це рядок 18 в `index.html` — замініть `CONV-LENS-HOST` і
`CONV-LENS-SITE-KEY` на свої значення і задеплойте.

**Не додавайте умову, яка пропускає тег на `?replay=1`.** Стара версія так робила, бо
колектор жив на тому ж домені. Тепер саме цей тег ставить міст, без якого 3D-реплей не працює.

## 5. Перевірити, що дані пішли

1. Відкрийте сайт, поклікайте.
2. Лінза → **Налаштування**: угорі блоку «Код для сайту» має бути зелений напис
   «Код працює: дані приходять».
3. Лінза → **Записи сесій** → відкрийте свіжу сесію. Для режиму «справжня сторінка»
   у плеєрі має зʼявитись сам сайт. Якщо замість нього зʼявився запис зі знімка і жовте
   повідомлення — міст не відповів: перевірте, що тег стоїть і що сайт не забороняє показ
   у фреймі (`X-Frame-Options`, `Content-Security-Policy: frame-ancestors`).

## 6. Прибрати стару лінзу

Тільки після того, як нова збирає дані.

У `homeboys-cutaway` код уже прибраний: видалені `api/`, `lens/`, залежність `@libsql/client`
і переписи в `vercel.json`. Лишається прибрати на боці Vercel:

- стару базу Turso старого проєкту (**Storage**) — спершу переконайтесь, що історія з неї
  вам більше не потрібна, див. наступний пункт;
- змінні `CONV_LENS_TOKEN`, `CONV_LENS_SALT` у налаштуваннях лендінгу.

Старий дашборд за адресою `/lens/` після деплою просто зникне (404).

## 7. Що зі старими даними

Їх можна не переносити — найпростіший шлях: нова лінза починає з чистого аркуша, а стару
базу лишити на місяць «на почитати» і потім видалити.

Якщо історія потрібна, **не копіюйте змінні руками**: Vercel → **Storage** → ваша база →
**Connect to Project** → виберіть новий проєкт. Vercel сам пропише `TURSO_DATABASE_URL`
і `TURSO_AUTH_TOKEN`, а Conv Lens шукає саме ці імена, тож нічого налаштовувати не треба.
Схема сумісна, міграції додадуть чого бракує самі. Але старі рядки писались
до появи мультисайтовості, тому в них порожній `site_id`, і в дашборді вони не зʼявляться,
доки ви їх не підпишете. У SQL-консолі Turso один раз:

```sql
UPDATE sessions  SET site_id = 'ВАШ_SITE_ID' WHERE site_id IS NULL OR site_id = '';
UPDATE events    SET site_id = 'ВАШ_SITE_ID' WHERE site_id IS NULL OR site_id = '';
UPDATE snapshots SET site_id = 'ВАШ_SITE_ID' WHERE site_id IS NULL OR site_id = '';
```

`ВАШ_SITE_ID` — це `id` сайту, не ключ: видно в `conv-lens sites` або в адресі дашборда.
Робіть це на копії бази; на великій таблиці подій запит не миттєвий.

Окремо врахуйте: старі записи 3D-сцени збережені у форматі `v1` з абсолютним часом кадру.
Плеєр читає і його, тож давні сесії відтворюються — ламати їх перепакуванням не треба.
